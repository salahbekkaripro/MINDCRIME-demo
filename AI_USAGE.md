# Usage de l’IA — prototype indépendant

Cette démonstration a été produite avec Codex à la demande de Salah-Eddine Bekkari, à partir du concept MINDCRIME et des orientations apportées par l’équipe. L’assistant a généré et adapté du code Java, React/TypeScript, des tests, la configuration et la documentation. Ce prototype ne doit pas être présenté comme du code rédigé manuellement par les étudiants ni comme leurs fonctionnalités universitaires livrées.

Les vérifications réalisées comprennent les tests Java, le build frontend et des parcours automatisés locaux des deux modes. Elles ne constituent pas une revue humaine ni une mesure de la part d’IA. Aucune approbation humaine individuelle ou estimation chiffrée n’est inventée ici.

Avant toute réutilisation dans le projet universitaire, les membres doivent comprendre, relire, adapter et tester les éléments retenus, puis tracer leurs contributions et l’aide reçue selon les consignes pédagogiques applicables. Le moteur métier fonctionne en Java sans dépendance obligatoire à une API d’IA.

Ce dépôt possède un historique distinct du dépôt universitaire et ne remplace pas son dossier de lancement ni ses livraisons.
